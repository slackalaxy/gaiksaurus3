# gaiksaurus3: an unofficial GTK3 port of (g)aiksaurus

**Porting of [(g)aiksaurus](https://aiksaurus.sourceforge.net/) from GTK2 to GTK3 was done *entirely* by Claude, by Anthropic.** Therefore, **no** credit goes to me for this AI slop. The program seems to build and run just fine on [CRUX](https://crux.nu/), however, be warned and use at your own risk.

## Changes
* installable icon and desktop file
* systray support (tested on Xfce)
* misc cleanups, e.g removed th Win folder

## Reasoning
The last version of (g)aiksaurus is 1.2.1, released in 2005. Also, I missed having a systray icon.
